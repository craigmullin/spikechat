# SpikeChat – Public Release Polish

## Objective

Prepare SpikeChat for public release as a polished portfolio project that can be linked from craigmullin.com.

The goal is **not** to add major functionality. Instead, make the project feel intentional, professional, and trustworthy while clearly positioning it as a creative tool.

---

# Philosophy

SpikeChat should be presented as a **conversation mockup studio**, not a "fake text generator."

The emphasis is on:

- UI/UX prototyping
- storytelling
- education
- presentations
- design
- creative projects

rather than deception.

---

# Copy Updates

Replace wording such as:

- Fake Chat
- Fake Conversation
- Fake Text Messages

with language such as:

- Fictional Conversation
- Conversation Mockup
- Conversation Studio
- Conversation Prototype
- Message Mockup

wherever it feels natural.

The goal is not to hide what the application does, but to describe it in professional language.

---

Create a lightweight landing page before entering the application.

## About SpikeChat

SpikeChat is a browser-based conversation mockup studio built as an independent software project by Craig Mullin.

It was created to make designing realistic messaging interfaces fast, flexible, and enjoyable.

Common uses include:

- UI and UX design
- application mockups
- storyboarding
- creative writing
- educational material
- presentations
- social media concepts

SpikeChat is intended for creating fictional conversations and interface mockups for creative, educational, and prototyping purposes.

# Out of Scope

Do NOT:

- redesign the application
- change editing workflows

- add cloud storage
- add major features

---

# Acceptance Criteria

The application should feel like a polished, public-facing portfolio project.

A prospective employer should come away thinking:

"This developer built a clean, thoughtful web application, deployed it successfully, and presented it professionally."

rather than:

"This is a fake texting app."
